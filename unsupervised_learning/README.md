# Unsupervised Learning

An important challenge in unsupervised learning is that the extracted results need domain expertise to evaluate the quality of the extracted insights.

> **Note:** Choosing between supervised and unsupervised learning for a task is not a binary choice and depends on the nature of the data and the problem at hand.

**Hybrid approaches:**
- Semi-supervised learning
- Transfer learning

## Unsupervised Learning Techniques

- **`Clustering`**
- **`Dimensionality reduction`**
- **`Association rule learning`**
- **`Anomaly detection`**
- **`Autoencoders`**
- **`Generative Adversarial Networks (GANs)`**
- **Density estimation**

## Key Objectives of Unsupervised Learning

### Pattern Discovery

- Clustering
- Association rule learning
- Anomaly detection: 
    - Isolation forest
    - One-class SVM
    - One-class logistic regression

### Dimensionality Reduction

- PCA
- t-SNE
- Autoencoders

### Featture Learning

Has applications in computer vision, natural language processing, and speech recognition, recommendation systems, and many other areas.

### Density Estimation

Has applications in generating new samples similar to the training data, detecting outliers and anomalies, improving the performance of machine learning models, and many other areas.

### Data Compression

Has applications in compressing large datasets, reducing the size of data for storage and transmission, and improving the performance of the downstream systems.
- Autoencoders for image compression

### Generative Modeling

Has applications in creating synthetic images and text, data augmentation for improving supervised learning models, simulating scenarios for decision-making or planning, and many other areas.

### Exploratory Data Analysis (EDA)

Has benefits in revealing structure and patterns in the data, identifying potential subgroups or clusters, and detecting outliers or anomalies.
