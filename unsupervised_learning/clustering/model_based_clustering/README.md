# Model-Based Methods

This type of clustering is based on the idea of using a model to group data points. Model-based clustering algorithms are used to identify clusters of data points that are similar to each other.

## Advantages

- Soft clustering (probabilisties of belonging to each cluster)
- Can capture clusters with different shapes and sizes

## Disadvantages

- Can be computationally expensive for large datasets (medium)
- Need to specify the number of clusters

## Algorithms

- **`Gaussian Mixture Models (GMM)`**
