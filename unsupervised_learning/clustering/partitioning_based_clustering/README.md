
# Partitioning Methods

This type of clustering is based on the idea of dividing the data into two or more groups such that the groups are more similar to each other than to the data points that are not in the same group.

## Advantages

- Simple and Fast for large datasets
- Works well with globular clusters

## Disadvantages

- Need to specify the number of clusters
- Sensitive to outliers
- Sensitive to initial centroids placement

## Algorithms

- **`K-means`**
