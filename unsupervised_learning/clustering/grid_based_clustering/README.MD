# Grid-Based Methods

This type of clustering is based on the idea of dividing the data into a grid and grouping data points based on their proximity to the grid lines. Grid-based clustering algorithms are used to identify clusters of data points that are close to each other.

## Advantages

- Computationally efficient for large datasets
- Robust to outliers
- Fast processing time (tipycally independent of the number of samples)

## Disadvantages

- Can't capture clusters with different shapes and sizes
